# Claude startup contract

Before doing any work in this repository:

1. Read `PROJECT_CONTEXT.md` completely.
2. Verify current branch, HEAD, working tree and upstream.
3. Do not treat the GitHub default branch as automatically canonical; use the branch topology documented in `PROJECT_CONTEXT.md`.
4. Do not merge, deploy, delete branches/worktrees or rewrite history unless explicitly required by the approved task.
